[color=#e06666][size=6][b]- Introduction -[/b][/size][/color]

RadioXL adds radio stations to Cyberpunk 2077 as real stations of the game's own radio. A station built on it plays on the Radioport, in every vehicle and on the radios placed around Night City, with its own name, icon and song titles, and the dial, the radio hotkey, the equaliser and the dashboard treat it exactly as they treat the stations the game ships.

A station mod is one small file and a folder of audio. RadioXL reads the rest from the files.

[i]TL;DR - your music, on every radio in the game, through the game's own radio.[/i]


[color=#e06666][size=6][b]- For Players -[/b][/size][/color]

RadioXL is a framework. Install it, then install stations built on it, or build one yourself in the time it takes to copy a folder of songs.

[b]Install[/b]
Drop the archive into your mod manager. The plugin and the scripts always travel together: installed apart, the scripts fail to compile.

[b]Uninstall[/b]
Remove RadioXL and every station built on it. RadioXL keeps nothing in your saves.

[b]Coming from RadioXL 0.1.0[/b]
A station written for 0.1.0 (a yaml, a script and an AudioXL sounds.json) does not play on this release. Its script still compiles, and the log says the station was seen. The station's author converts it to the manifest below; the songs and the icon are reused as they are.


[color=#e06666][size=6][b]- Adding a station -[/b][/size][/color]

A station is one folder under
[code]red4ext\plugins\RadioXL\stations\<YourMod>\[/code]
holding a [b]station.json[/b] and the audio files it names.

[quote][code]{
  "name": "radio_station_20_tool",
  "displayName": "104.9 Tool FM",
  "icon": "tool_fm",
  "atlas": "toolfm\\gui\\tool_fm.inkatlas",
  "tracks": [
    { "file": "audio/Tool - Vicarious.mp3", "title": "Tool - Vicarious" },
    { "file": "audio/Tool - Jambi.mp3",     "title": "Tool - Jambi" }
  ]
}[/code][/quote]

[list]
[*][b]name[/b] is the station's identity: letters, digits and underscores, unique among installed stations.[/*]
[*][b]displayName[/b] starts with the frequency. The dial is sorted by it, so 104.9 lands between 103.5 and 106.9. Taken: 88.9, 89.3, 89.7, 91.9, 92.9, 95.2, 96.1, 98.7, 99.9, 101.9, 103.5, 106.9, 107.3 and 107.5.[/*]
[*][b]icon[/b] and [b]atlas[/b] are optional: an inkatlas part and the atlas holding it, shipped in an archive of your own. [b]icon[/b] can instead name an icon record the game or another mod already has, such as [b]UIIcon.RadioHipHop[/b], with no atlas and no archive. Leave both out and the station shows the RadioXL glyph.[/*]
[*][b]tracks[/b] play in a random order, each song once before any repeats, the way a vanilla station plays. WAV, MP3, OGG and FLAC. A track can be a [b]url[/b] instead of a [b]file[/b]: a live MP3 stream, as the station's only track.[/*]
[*][b]title[/b] is optional on a track. It is the song name in the Radioport's radio popup; an untitled song plays everywhere a titled one does and its name reads blank. World radios and the car dashboard show no song names for any station.[/*]
[*][b]ident[/b] is optional on a track. true marks a station ident, jingle or ad: one plays after every third song, and shows no title.[/*]
[*][b]news[/b] is optional. true lets the news reach the station - Stanley's bulletins and greetings, and N54 News - the same way it reaches the game's own stations.[/*]
[/list]

No durations, event names, indices, records, yaml or script. RadioXL reads each track's length from the file and builds everything else at load. A manifest with a mistake in it is skipped, and the log names the file and the line.


[color=#e06666][size=6][b]- Stations that stream -[/b][/size][/color]

A station can play a live internet radio stream instead of music files. AudioXL fetches nothing from the internet until you allow it, in [b]red4ext\plugins\AudioXL\AudioXL.ini[/b]:
[quote][code][Network]
allowHttpConnections = true
allowedHost = ice1.somafm.com[/code][/quote]
Use the host the station's own page names; one [b]allowedHost[/b] line per host. A station that stays silent usually needs one more host: AudioXL's log names the one it refused.

[b]AudioXL creates AudioXL.ini on its first start[/b], with everything off, and an update leaves it alone. Under Mod Organizer 2 the file is in Overwrite.

A stream station joins the broadcast live when you tune in, after a second or two of buffering, and shows the station's own title rather than the song playing.


[color=#e06666][size=6][b]- Settings -[/b][/size][/color]

Four tabs in the Redscript Configuration Framework panel. Every station and every song on them is read from the game when a save loads, so a song added by any radio mod is listed with nothing extra to install.

[b]Controls[/b]
[*][b]Next song / Previous song.[/b] One set of keys for both radios: in a vehicle they act on the vehicle radio, on foot on the Radioport, the metro included. Press a keyboard key or a controller button to bind one; Escape clears it. A key bound in the game's own settings still does what the game says, so pick one the game does not use.[/*]
[*][b]Next station / Previous station.[/b] Move along the dial in the same order the radio does, skipping the stations set aside on the Stations tab. Unbound by default.[/*]
[*][b]Show what's playing.[/b] Puts the radio popup on screen for the song playing now. Unbound by default.[/*]
[*][b]Never play this song again.[/b] Switches the song that is playing off and moves on. Unbound by default.[/*]
[*][b]Jump to my station.[/b] Tunes straight to the station set on the My station tab, whether or not the automatic tuning is switched on. Unbound by default.[/*]
[*][b]Hold a modifier with the keys.[/b] Gives every key a second row: a key that must be held down with it. A key with its modifier held wins over the same key bound on its own, so F3 can be the next song and Shift+F3 the next station.[/*]
[*][b]Separate keys for the Radioport.[/b] Gives the Radioport its own set of keys, used on foot instead of the set above.[/*]
[*][b]Show the song on the Radioport.[/b] The vehicle radio's song popup, shown for the Radioport as well when a song changes.[/*]
[*][b]Show the song as an on-screen message.[/b] The station and the song at the left of the screen when a song changes. Off by default.[/*]

[b]My station[/b]
[*][b]Tune to my station.[/b] The switch for this tab.[/*]
[*][b]Station.[/b] The station to tune to. It is remembered by name, so it stays the same station after you add or remove station mods. If that station is not installed, nothing is tuned.[/*]
[*][b]When getting into a car / When the car radio is switched on / When the Radioport is switched on.[/b] The three moments the radio is tuned.[/*]
[*][b]Even if the Radioport is on.[/b] Tunes the car radio even when the Radioport is already playing another station. Off leaves the Radioport's station alone.[/*]
Nothing is tuned while the game blocks radio input: in a police vehicle, during a scripted drive, as Johnny, and before the car radio is unlocked.

[b]Stations[/b]
One section per station, in dial order.
[*][b]Keys step over this station.[/b] The next and previous station keys skip it. It can still be picked from the radio itself.[/*]
[*][b]Its songs.[/b] One row each, with three settings: [b]On[/b] plays as normal; [b]Off[/b] is skipped whenever it comes up, and the next song on that station plays instead; [b]Off while streaming[/b] plays as normal and is skipped whenever the game's Streamer Mode setting is on. Songs the game marks as not streamer friendly start there. A song added by a station mod carries no such mark and starts On, so this is where you set one.[/*]
The top of the tab says whether Streamer Mode is on right now, and while it is, every song being skipped for it is marked in its own row. If every song on a station is set to Off, the station plays as normal, and the next and previous keys step through them.

[b]Mute[/b]
[*][b]Mute station idents.[/b] The station's own spot between songs: its name, its frequency and whatever its host says over them. Each station keeps its own, so this is what silences Pacific Dreams' host. Applies from the next song.[/*]
[*][b]Mute DJ announcements.[/b] Everything that takes a slot between your songs: Stanley's news bulletins, Maximum Mike's song intros and Growl FM's Ash. Kurt Hansen is left alone: he broadcasts over Dogtown rather than through your radio. A station's own spot is the setting above, not this one, and songs are never affected.[/*]
Both are off by default, both take effect straight away, and switching either back puts the sound in place exactly as it was.
[*][b]Mute the radio when...[/b] Twelve switches, all on by default, and they apply to every station on the Radioport, the game's own included. Each is a situation in which the game silences the radio: a scene, a phone call, a club, fast travel and so on. On, the Radioport goes quiet there exactly as the game does. Off, it keeps playing through it. A switch stands for a situation: turning off the holo call switch also lifts the locks a call brings with it, and the same for a scene and a vehicle scene.[/*]
Combat and police heat have no switch. The game ducks and stops every station in those.


[color=#e06666][size=6][b]- A key does nothing -[/b][/size][/color]

Keys are ignored in menus and in photo mode, and the song and station keys only work with a radio on. Check the key is bound on the Controls tab and not only in the game's own settings, and that its modifier, if you use them, is held down. A station key does nothing while the radio plays through another mod's own player rather than the game's, which is how RadioExt stations work: pick a station from the radio itself and the keys work again. If the Stations tab says the station list has not been read, load a save and open the panel again; the list is read when a game loads, not at the main menu.


[color=#e06666][size=6][b]- A station is not showing up -[/b][/size][/color]

Install RedLogger and read r6\logs\mods\RadioXL.log after a launch. Every manifest fault is reported as [i]YourMod/station.json:<line>: what is wrong[/i], and a station with a fault is skipped whole. A station with no line in the log at all was not found: check the folder path above.

If a station appears but sorts oddly against another one, check the frequency at the front of displayName: two stations on the same number have no defined order between them.


[color=#e06666][size=6][b]- Known Limits -[/b][/size][/color]

[list]
[*]Tuning away from a station and back picks the song up where the station has got to, the way a vanilla station does.[/*]
[*]On a news station, Stanley's greetings reach the station you are listening to. A news bulletin goes to one station at a time, between songs, chosen by the game from every news station with a radio nearby, switched on or not: in the city a nearby station of the game's often takes it, so news is dependable only away from other radios. The game's own stations follow the same rule.[/*]
[*]Up to 127 stations.[/*]
[*]RadioXL replaces the game's station cycling, so it cannot be installed beside RadioExt or RadioXL 0.1.0.[/*]
[/list]
